Savesmart_ROSCA is a digital platform for managing ROSCA groups. 
ROSCA stands for "Rotating Savings and Credit Association" - a system where group members contribute money regularly and each member takes turns receiving the full pooled amount.

This system helps groups, families, and communities save money with discipline, track contributions, and manage payouts transparently and securely.

Key Features
- Group Management: Create and manage multiple ROSCA groups
- Member Registration: Add members and set payout order/rotation
- Contribution Tracking: Record and monitor weekly/monthly contributions
-  Automated Payouts: System automatically schedules who receives funds and when
- Payment Reminders: Notifications for members with pending contributions
- Reports & Analytics: Generate reports on total funds, defaulters, and payouts
- Secure Access: Role-based login for Admins and Members

 How ROSCA Works
1. Group Setup: forexample X members agree to contribute amount T per cycle
2. Contribution: All members contribute at each cycle
3. Payout: All contributions are pooled and given to 1 member per cycle
4. Rotation: The cycle repeats until every member has received a payout

Benefit: Members get access to a large sum of money early + financial discipline

 Installation & Setup
 
1. Clone repository
git clone https://github.com/Betson12541/Savesmart_ROSCA.git

2. Navigate to project folder
cd Savesmart_ROSCA

3. Setup Database
Import database.sql file into phpMyAdmin or MySQL

4. Configure Database Connection
Update config/database.php with your DB name, username, and password

5. Run on Local Server
Place folder in htdocs if using XAMPP
Access: http://localhost/Savesmart_ROSCA
